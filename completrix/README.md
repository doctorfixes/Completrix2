# Completrix v4

A deterministic architecture-intelligence engine for designing, decomposing, evolving, and governing software systems.

## Context

Modern software development suffers from vague requirements, inconsistent architecture, duplicated systems, and drift over time — while AI tools generate code but not structure.

Completrix is the missing layer: the architecture brain that sits above systems, teams, and codebases. It turns ambiguity into clarity, ideas into architecture, portfolios into coherent systems, and repos into self-improving organisms.

## Features

- **Clarification Engine**: Turns vague intent into structured understanding
- **Decomposition Engine**: Breaks systems into modular subsystems
- **Creation Engine**: Generates complete FinalSystemSpec + ExecutionPlan
- **Portfolio Optimizer**: Analyzes multiple systems for duplication and consolidation
- **Evolution Planner**: Produces multi-phase evolution roadmaps
- **Self-Improvement**: Gap scanning, fix generation, and self-governance planning
- **Runtime**: Agent pipeline orchestration with streaming and parallel execution
- **Governance**: Invariant/constraint enforcement and drift monitoring
- **CLI**: Eight deterministic commands — scriptable and CI/CD-friendly

## Quick Start

```bash
npm install
npm run build
completrix clarify "Build a microservices e-commerce platform"
```

## Usage Modes

| Mode | Input | Output |
|------|-------|--------|
| Single-System | Feature / idea / spec | Clarification → Decomposition → Spec → Plan → Evolution |
| Portfolio | Multiple systems | Cross-system inference → Optimization → Roadmap |
| Self-Bootstrap | RepoIndex | Gap scan → Fix plan → Governance plan |
